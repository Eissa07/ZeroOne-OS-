## 🌌 ما هو ZeroOne OS؟  
## 🌌 What is ZeroOne OS?

<div dir="rtl" align="right">

**ZeroOne OS** ليس مجرد تطبيق ويب. إنه **نظام تشغيل ثلاثي الأبعاد** طموح يعمل داخل متصفحك. إنه **اللبنة الأولى في ثورة كلمات المرور والتشفير**، حيث تتحول الملفات إلى أسرار مخبأة في الفضاء الرقمي، مؤمنة بتشفير عسكري ومتصلة بسحابة خاصة.

</div>

**ZeroOne OS** is not just a web application. It is an ambitious **3D Operating System** that runs inside your browser. It is the **first building block in a revolution of passwords and encryption**, where files become secrets hidden in digital space, secured by military‑grade encryption and connected to a private cloud.

## ✨ المميزات الثورية  
## ✨ Revolutionary Features

| الميزة (Feature) | الوصف (Description) |
| :--- | :--- |
| 🖥️ **نوافذ ثلاثية الأبعاد**<br>`3D Windows` | نوافذ نظام تفاعلية تطفو في الفضاء، قابلة للسحب والتحريك.<br>*Interactive system windows floating in space, draggable and movable.* |
| 🔐 **خزنة الأسرار**<br>`Secret Vault` | تخزين الملفات بشكل آمن في IndexedDB مع **تشفير AES-256** قبل الحفظ.<br>*Securely store files in IndexedDB with **AES-256 encryption** before saving.* |
| ☁️ **التخزين السحابي**<br>`Cloud Storage` | جاهز للتكامل مع **Cloudflare R2** (10 جيجابايت مجانية). ارفع ملفاتك المشفرة إلى السحابة واسترجعها من أي مكان.<br>*Ready for integration with **Cloudflare R2** (10GB free). Upload your encrypted files to the cloud and retrieve them from anywhere.* |
| 🤖 **ذكاء اصطناعي محلي**<br>`Local AI` | نموذج **DistilBERT** يعمل داخل المتصفح (بدون إنترنت). اكتب أوامرك بالعربية ("افتح الخزنة") والنظام ينفذها.<br>*A **DistilBERT** model runs inside the browser (offline). Type commands in Arabic or English and the system executes them.* |
| 🎥 **مركز وسائط متكامل**<br>`Media Center` | التقط لقطات شاشة (PNG)، سجل فيديو للمشهد (WEBM)، وصدر المشروع بصيغة GLTF.<br>*Take screenshots (PNG), record scene videos (WEBM), and export the scene as GLTF.* |
| 🧩 **قابل للتوسع بالكامل**<br>`Fully Extensible` | أضف مميزاتك الخاصة بسهولة عبر ملف `extensions.js`. لا حاجة لتعديل الكود الأساسي!<br>*Add your own features easily via the `extensions.js` file. No need to touch the core code!* |
| 📱 **يعمل على الموبايل**<br>`Mobile Ready` | واجهة متجاوبة بالكامل مع دعم اللمس والإيماءات.<br>*Fully responsive interface with touch and gesture support.* |
